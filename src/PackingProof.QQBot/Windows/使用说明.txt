PackingProof QQBot 0.0.1 使用说明

一、首次使用

1. 确保安装并运行 PackingProof 主程序，并已在主程序中开启扩展 API
2. 双击“启动机器人”
3. 按提示输入 QQ AppID、QQ AppSecret 和 PackingProof 地址
4. 在 PackingProof 弹窗中批准授权
5. 配置完成后机器人会自动启动

二、日常使用

私聊机器人并直接发送完整快递单号

机器人找到录像后会先说明录像数量、时间、时长和大小，再发送文件

一条 QQ 消息最多回复三段录像。如有剩余，回复“继续”即可发送下一批

三、QQ群使用

确认 QQ 开放平台已开通群能力后，将机器人加入目标群并 @机器人发送单号

控制台会显示群 OpenID。关闭机器人后双击“添加群白名单”，粘贴群 OpenID，再重新启动机器人

四、视频大小

双击“视频发送设置”可设置单个录像的最大大小，默认 190 MB

录像超限时，PackingProof 主机会生成临时副本，原始录像不会被修改
